# V2 实施记录

日期：2026-11-20。分支：feat/wechat-miniapp-v2。

## 已落地：P1 第一批服务器基础

- 新增独立 backend/，原 app/ 本机版入口和运行数据不改。
- 独立 .venv-v2，新增依赖锁；SQLAlchemy + Alembic 初始化服务器结构。
- SQLite v5 只读一致性导入；目标非空拒绝覆盖，逐表规范化内容摘要核验，附件复制前后校验 SHA-256。
- PostgreSQL 导入后修正整型 ID sequence，继续保存新版本不冲突。
- 新增用户与个人事件已读表，旧全局已读仅迁移给原拥有者；尚未开放用户登录接口。
- 将五栏目的列表发现改为独立调度和后台任务，复用已核实的官网请求参数、标题、副标题和列表顺序。
- 数据库持久化任务、唯一任务键、到期领取、资源互斥、租约续期、失效提交回滚、指数退避和尝试上限。
- API 启动不启动采集线程，不执行数据库迁移；提供带开发管理令牌保护的来源、文章和任务查询。
- 提供仅监听本机的 Compose 开发配置与 Dockerfile；尚未用于正式部署。
- 准备事项整理到 USER_PREPARATION.md。
