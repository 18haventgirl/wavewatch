3. 微信开发者工具选择“导入项目”，目录选 `D:\Workplace\传奇开发\信息监测\miniprogram`，核对 AppID 为上述值。无需开启云开发。
4. 选择微信登录，首次填写终端显示的邀请码。若微信返回测试号不支持、AppID 无效或其他权限提示，把错误文字告诉我，不要发送 AppSecret。

## 网络边界

当前编译默认接口为 http://127.0.0.1:8842，用于本机开发者工具联调。工程保持 `urlCheck: true`，没有自动关闭域名校验。若工具报告“域名不在合法列表”，先记录错误，按测试号实际能力选择合规的调试环境或 HTTPS 联调地址，不能把这个提示当作登录接口已失败。

若你决定仅在本机模拟器调试，可由你在开发者工具“详情 → 本地设置”中启用“不校验合法域名……”的本地调试选项；它只用于当前开发环境。工程没有替你修改此设置，手机联调与发布仍需单独验证合法 HTTPS 域名。

手机上的 127.0.0.1 是手机自己，不能用它访问电脑。真机预览需要可达的 HTTPS 后端，并按实际账号要求配置域名；尚未做真机登录验收。

切换后端地址后需重新构建：

```powershell
cd miniprogram
$env:TARO_APP_API_BASE = 'https://你的联调域名'
npm ci --no-audit --no-fund
npm run typecheck
npm run build:weapp
```

AppSecret、开发管理令牌、引擎 key 均不进入小程序。编译目录 dist 和 node_modules 不入 Git，package-lock.json 记录依赖。
